三、开启 TLS 1.2 有什么影响？

TLS 是 HTTPS 使用的加密协议。

TLS 1.2 是目前非常成熟、兼容性非常好的 HTTPS 协议版本。

开启 TLS 1.2 一般不会影响正常使用，反而有利于现代 HTTPS 网站和软件正常建立安全连接。

例如：

项目 影响
HTTPS 网站 正常
GitHub 正常
Sublime Package Control 有利于正常连接
Windows Update 正常
浏览器 正常
新软件 正常
HTTP 网站 不受影响

因此，如果 Windows 中没有启用 TLS 1.2，建议开启。
